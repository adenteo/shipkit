# Prompt shapes

Short, concrete, visual. Say what is in the frame, the medium, the light and the
palette. Say what must not appear. Keep shared style in `style_preamble`.

## Moodboard (explore)

```
A 3x2 moodboard grid for <app one-liner>, for <audience>. Direction: "<name>",
<feeling in a few words>. Tiles: a close-up material texture (<material>), palette
swatches in <hex list>, type specimen shapes in the style of <font pairing> (shapes
only, no readable words), two small UI fragments (a <card type> and a <control>)
in that style, one atmospheric photo of <setting>. Even gutters, flat lay,
soft natural light. No logos, no lorem ipsum, no readable text.
```

## Hero screen idea (explore, never shipped)

```
An iPhone screen concept for <app>, the <screen name> screen, in the "<direction>"
style: <palette>, <font feel>, <density>. Shows <the key elements>. Straight-on,
no device frame, no status bar text, no readable words, placeholder lines for text.
```

Say in the contact sheet that these are concepts. Real screenshots come from the
running app (ship-screenshots).

## App icon concepts (explore)

```
An iOS app icon concept for <app>: <one simple symbol idea>, centered, bold and
readable at 60px, <palette>, <material or flat>, filling a rounded square edge to
edge, no text, no letters, no thin lines.
```

Make six with different symbol ideas rather than six versions of one. The final
icon is redrawn or refined in ship-brand.

## Onboarding or empty-state illustration (produce)

```
<style_preamble> a <subject doing something that shows the benefit>, simple
composition with the subject in the middle third, generous empty space above for a
headline set in code, plain <bg hex> background.
```

## Sticker, badge or mascot pose (produce, cut out)

```
<style_preamble> <subject and pose>, large and centred, with a clear even margin of
plain flat <bg hex> background on all four sides. The subject must not touch any
edge or corner.
```

## What makes images look AI-made (avoid)

- Fake text and squiggles that look like writing. Ask for "no readable text".
- Everything glossy, rim-lit and symmetrical. Ask for a specific medium (gouache,
  risograph, paper cut, flat vector with 2px strokes) and real light.
- Over-detailed backgrounds. Ask for plain backgrounds and empty space.
- Drift across a set. Use a reference image and one shared preamble.
